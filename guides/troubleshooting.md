# Troubleshooting

A general JSON Schema and a canonical BEP Studio schema serve different purposes. If conversion fails, inspect the path in the report and convert the unsupported constraint explicitly. A renamed column must also update required-column names. Select defaults must belong to options. Duplicate stable keys or table-column names require correction.

If automation is missing, check the required title/name and date headers, confirm the mapping and ensure the source is an active Project BEP. NONE intentionally disables detection. Ambiguous tables need an explicit choice.

A stale section must be reloaded before editing again. Existing historic snapshots retain their original contents. Delimiter-separated historic cells containing literal pipes require manual review because their original boundaries are unavailable.

# AI-assisted schema authoring

Read AGENTS.md, start from a validated example and produce a canonical BEP Studio JSON file. Preserve stable keys during revisions. Use string options and explicit table-column requirements. Ask the schema author to decide any ambiguous project automation mapping. Run the standalone validator and give the user the JSON file plus its report.

The public documentation cannot identify a visitor's subscription. New visitors can explore the Demo or registration. Existing users authenticate in BEP Studio to use authorized private features. An external agent has no account or project access through these documents. This release adds no agent API or MCP server.
